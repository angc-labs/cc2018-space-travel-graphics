- **W / S:** inclinar la camara
- **Rueda del mouse / flechas arriba y abajo:** zoom
- **Teclas 1 al 7 (Viaje Rapido):**

  - `2`: Mercurio
  - `3`: La Tierra
  - `4`: La Luna
  - `5`: Marte
  - `6`: Jupiter
  - `7`: Cinturon de Asteroides
